# razbor-servisa

**Скилл для Claude Code, который превращает сервис без API в инструмент, которым агент управляет за вас.**

У вас есть личный кабинет — маркетплейса, CRM, банка, сервиса рассылок. Данные там есть, но забрать их можно только руками: зайти, открыть раздел, скопировать в таблицу. Каждый день одно и то же.

Этот скилл учит Claude Code решать такую задачу целиком: он смотрит, **как сайт разговаривает со своим сервером**, и собирает маленькую программу, которая повторяет тот же разговор. После этого вы просто пишете в чат «покажи аналитику за неделю» — и получаете данные.

---

## Зачем это нужно

У больших сервисов есть «разъём для программ» — API. Подключил ключ, и робот сам забирает данные.

У многих сервисов такого разъёма нет. Особенно у российских: есть красивый личный кабинет и всё. Официальный ответ — «работайте руками».

Но кабинет-то как-то показывает вам цифры. Значит, он сам ходит за ними на сервер. Скилл подсматривает этот поход и учит агента ходить туда же напрямую.

**Метафора.** Представьте, что в дом не проведён водопровод, и вы каждый день носите воду вёдрами из колодца. Скилл не улучшает вёдра — он находит, откуда идёт вода, и прокладывает трубу.

---

## Как это работает

Четыре шага, всё делает агент — от вас нужны короткие ответы:

1. **Проверяет, есть ли у сервиса официальный API.** Если есть — собирает всё по документации, это самый быстрый путь.
2. **Если API нет — смотрит, как работает кабинет.** Вы открываете свой кабинет в браузере, нажимаете `F12` (режим разработчика) и щёлкаете нужный раздел. В этот момент видно все запросы, которые страница отправляет серверу.
3. **Собирает маленькую программу (CLI)** под ваш проект: одна команда — одна задача. «Показать заказы», «выгрузить аналитику», «обновить остатки».
4. **Учит агента звать эту программу самому** — по обычной человеческой фразе, без команд и терминала.

## Установка

Скилл — это просто папка с текстовым файлом, которая лежит в `~/.claude/skills/`. Claude Code подхватывает её при запуске. Никакой сборки и настройки не нужно.

Выберите любой способ — они дают одинаковый результат.

### Способ 1 — попросить Claude словами (самый простой)

Откройте Claude Code — в приложении или в терминале, неважно — и отправьте в чат такое сообщение:

> Установи мне скилл: склонируй https://github.com/Ntmib/razbor-servisa.git в папку ~/.claude/skills/razbor-servisa

Claude всё сделает сам и скажет, когда готово. **Перезапустите Claude Code** — скилл появится.

### Способ 2 — одна команда в терминале

Если вы дружите с терминалом, это займёт три секунды:

```bash
git clone https://github.com/Ntmib/razbor-servisa.git ~/.claude/skills/razbor-servisa
```

Перезапустите Claude Code.

### Способ 3 — вручную, без единой команды

Для тех, кто не хочет иметь дела ни с терминалом, ни с командами:

1. На этой странице нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Распакуйте скачанный архив двойным щелчком. Появится папка `razbor-servisa-main`.
3. **Переименуйте её** в `razbor-servisa` (уберите `-main` в конце).
4. Откройте Finder и нажмите `Cmd + Shift + G`.
   *На Windows — откройте Проводник и щёлкните в адресную строку.*
5. Вставьте путь и нажмите Enter:
   - macOS: `~/.claude/skills`
   - Windows: `%USERPROFILE%\.claude\skills`
   *Если такой папки нет — создайте её сами: внутри `.claude` создайте папку `skills`.*
6. Перетащите переименованную папку `razbor-servisa` в открывшуюся папку `skills`.
7. Перезапустите Claude Code.

### Проверка, что скилл встал

Напишите в чат Claude Code:

> Какие скиллы у тебя есть?

В списке должен появиться **razbor-servisa**. Если его нет — проверьте, что путь получился ровно такой: `~/.claude/skills/razbor-servisa/SKILL.md`.

### Обновление

Если ставили способом 1 или 2 — попросите Claude «обнови скилл razbor-servisa» либо выполните:

```bash
git -C ~/.claude/skills/razbor-servisa pull
```

Если ставили вручную — скачайте ZIP заново и замените папку.

## Как пользоваться

Никаких специальных команд учить не нужно. Откройте Claude Code в папке своего проекта и напишите человеческой фразой, что вам нужно:

> Разбери сервис «НазваниеСервиса» — мне нужна оттуда еженедельная аналитика по клиентам

Дальше агент ведёт вас сам: спросит название сервиса, проверит документацию, при необходимости попросит открыть кабинет и нажать `F12`, соберёт инструмент и проверит его на живом запросе.

**Живые примеры фраз, на которые скилл откликается:**

- «У этого сервиса нет API, а мне нужно выгружать заказы»
- «Посмотри через режим разработчика, как этот сайт получает данные»
- «Собери CLI под мой личный кабинет»
- «Хочу, чтобы агент сам забирал статистику из кабинета рассылок»

**Типичные сценарии:**

| Задача | Что получится |
|---|---|
| Каждое утро сводить продажи из кабинета маркетплейса | Команда «покажи продажи за вчера» — данные в чат за секунду |
| Собирать статистику рассылок в один отчёт | Агент сам забирает цифры и складывает в таблицу |
| Проверять статусы заявок в CRM без захода в кабинет | Одна фраза вместо пяти кликов |

## Что нужно, чтобы начать

- **Claude Code** — установленный и работающий.
- **Свой аккаунт** в сервисе, который автоматизируем (действующая подписка или доступ).
- **Браузер** — обычный, которым вы и так пользуетесь.
- Уметь программировать **не нужно**. Код пишет агент.

## Границы и безопасность

Прочитайте, это важно — скилл встроен так, чтобы не давать себе лишнего.

- **Только свой кабинет и свои данные.** Скилл предназначен для автоматизации аккаунта, к которому у вас есть законный доступ. Он не помогает попасть туда, куда вы не имеете права заходить.
- **Секреты не утекают в код.** Токен, cookie, пароль — всегда в отдельном файле `.env`, который не попадает в репозиторий. Скилл следит за этим и предупреждает.
- **Читать — свободно, менять — только с вашего «да».** Посмотреть данные агент может сразу. Любое действие, которое что-то меняет на стороне сервиса (отправить, удалить, оплатить), — сначала описывает, потом ждёт подтверждения.
- **Капча не обходится.** Если сервис поставил защиту от роботов — это стоп-сигнал, а не задача.
- **Правила сервиса — на вашей стороне.** У каждого сервиса свои условия использования. Убедитесь, что автоматизация вашего собственного аккаунта ими не запрещена.

**Чем этот скилл не является:** это не парсер чужих сайтов, не сборщик чужих данных и не обход защиты. Это способ не делать руками то, что вы и так каждый день делаете руками в своём кабинете.
